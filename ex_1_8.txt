Exercise 1.8  Provide a step-by-step description of the sequence of operations
that must take place within a MIPS processor to fetch and execute the "load
word" instruction.


Solution 1.8
Load World
lw  Rt, offset(Rs)

Fetches a word from memory at location specified in `Rs` with some optional
`offset`. The fetched word gets stored in `Rt`. This is an _immediate format_
instruction.
1. The MIPS CPU fetches the next instruction from the `PC`, which is
basically a register that tells the CPU where to get the next instruction.
2. For the purpose of this exercise the next instruction is a Load Word
instruction.
3. The instruction is fetched from the address specified in the `PC` into
the `IR` and the PC is incremented by 4 (instructions are 32-bits).
4. Two 5-bit operands in the `LW` instruction specify the source and
destination registers. The `Rs` specifies the memory address to fetch
from and the `Rt` specifies the 32-bit register the word will be stored in.
The `LW` opcode is decoded.
5. The instruction is executed. The CPU adds the optional offset to the
value from the `Rs` register and the CPU performs a memory read at the 
specified address. The value is fetched (some time later since memory
reads are slow, CPU idles while waiting for the value) and stored in `Rt`.
6. The 32-bit value fetched is loaded into the `Rt` register. This is the
result of the operation, the operation is finished and the CPU executes
the next instruction.

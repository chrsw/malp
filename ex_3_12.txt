Exercise 3.12 Assuming hte use of the two's complement number system find
the equivalent decimal values for the following 8-bit binary numbers:
(a) 10000001
(b) 11111111
(c) 01010000
(d) 11100000
(e) 10000011


Solution 3.12
(a) 10000001
Start with the problem input:
10000001
Using the precure from Section 3.9 ("scan from right to left, leaving all
least significant zeros and the first one unchanged, complement the remaining
digits")
01111111 = -127
Repeat for the rest of the Exercise:
(b) 11111111 -> 00000001 = 1, -1
(c) 01010000 not negative, 80
(d) 11100000 -> 00100000 = 32, -32
(e) 10000011 -> 01111101 = 125, -125
